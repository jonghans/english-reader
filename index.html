GitHub 동기화 설정

GitHub Pages 주소에서 저장소 정보가 자동 감지되었습니다.
이 브라우저에만 안전하게 보관됨
🔑 Fine-grained PAT 토큰 발급 방법 (1분)
  1. GitHub 로그인 → 우측 상단 프로필 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token 클릭 → 이름 입력 후 Repository access에서 Only select repositories로 이 저장소 선택
  4. Permissions → Repository permissions → Contents를 Read and write로 변경 후 생성
  5. 발급된 토큰(github_pat_...)을 위 입력칸에 붙여넣고 저장하세요.

* Public 저장소라면 다른 기기에서는 토큰을 입력하지 않아도 지문을 자동으로 읽어올 수 있습니다!
